# Aura v1.4 control-plane features

The public `bin/aura-cycler` entrypoint is separated from the hardened runtime (`bin/aura-cycler-runtime`) and the retained v1.3 feature engine (`bin/aura-cycler-core`). This makes real-system failures easier to bisect and keeps user-facing state management away from wallpaper internals.

## Wallpaper history and favorites

Aura records successful wallpaper transitions in owner-only local state. History is bounded to 100 entries and deduplicates consecutive duplicates. Nothing is uploaded.

```bash
bin/aura-cycler history list
bin/aura-cycler history previous
bin/aura-cycler history apply 3
bin/aura-cycler history clear
bin/aura-cycler favorite
bin/aura-cycler favorites list
bin/aura-cycler favorites apply 2
bin/aura-cycler favorites remove 2
```

`previous` and `undo` are aliases for `history previous`.

## Theme live-sync scope

Palette generation still happens normally. The scope controls which running applications Aura asks Omarchy to refresh after each wallpaper change.

```bash
bin/aura-cycler theme-scope shell
bin/aura-cycler theme-scope terminals
bin/aura-cycler theme-scope editors
bin/aura-cycler theme-scope all
```

- `shell`: wallpaper, generated theme and Omarchy shell; no known app-refresh helpers.
- `terminals`: shell plus terminal/tmux/btop refresh helpers.
- `editors`: terminals plus VS Code, Obsidian, Helix and OpenCode helpers.
- `all`: existing v1.3 behavior, including browser/GNOME helpers.

Unknown subprocesses are never suppressed. The default is `all` for backward compatibility.

## Manual scenes

Scenes are conservative local presets and deliberately never enable weather or online wallpaper networking without a separate explicit user action.

```bash
bin/aura-cycler scene list
bin/aura-cycler scene status
bin/aura-cycler scene apply focus
bin/aura-cycler scene apply gaming
bin/aura-cycler scene apply battery
bin/aura-cycler scene apply ambient
```

Automatic AC/battery/app triggers are intentionally deferred until real-system testing.

## Diagnostics and privacy

`doctor` is read-only and does not perform network requests:

```bash
bin/aura-cycler doctor
bin/aura-cycler doctor --json
```

Coordinates are redacted by default:

```bash
bin/aura-cycler privacy
bin/aura-cycler privacy --full
bin/aura-cycler config export
bin/aura-cycler config export --private
```

## Cache maintenance

Only Aura-generated palette JSON is pruned. Aura intentionally does not delete wallpaper files because users may place their own images in configured wallpaper directories.

```bash
bin/aura-cycler cache status
bin/aura-cycler cache prune-palettes 30
```
